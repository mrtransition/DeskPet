填写连接信息

云端服务需要 API Key；Ollama 等本地服务无需 Key，确认地址可访问即可。
演示模式无需填写任何信息，直接点「下一步」即可。
保存前先测试，能及时发现地址或 Key 的问题

隐私与数据位置

DeskPet 不注册账号、不做埋点，所有数据默认留在本机。
  • 数据目录：—
  • 密钥存储：Windows Credential Manager
  • 出站请求：仅在你发起对话、使用天气 / 联网搜索或检查更新时访问对应服务，不做任何后台遥测。
  • 敏感能力：剪贴板感知、久坐 / 喝水提醒、天气与联网搜索默认关闭；截图与语音输入尚未实现。
这些信息随时可在「设置 → 隐私」查看。看完本页或点「跳过」之后，引导不会再次自动弹出；如有需要，可从「设置 → 关于」重新打开。
