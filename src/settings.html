皮肤 FR-SKN-001 内置 3 套

导入后优先替代内置矢量形象，仍保留拖拽 / 点击 / 提醒等窗口交互。自定义形象请使用「导入八态单图」（4×2 自动切割）或「导入皮肤包」（.deskpet-skin.zip）；单张图片与 Codex 宠物导入入口已关闭。
八态单图规则：单张图按 4 列 × 2 行排列，按行读取 8 个状态，顺序固定为 idle / happy / sleep / work / click / drag / error / talk。导入时逐格切割、裁掉格内留白，并统一画布和底边对齐，切换状态时角色不会跳动；背景需为透明或浅色棋盘格。
皮肤包规范见 docs/皮肤与图集规范.md：skin.json（name 必填，states 映射八态）+ 八态图片（png / gif / webp）+ 可选音效（ogg / mp3 / wav），整包 ≤128 MB、单文件 ≤64 MB、解压 ≤256 MB、≤200 个条目；缺失状态回退 idle。Codex 宠物导入入口已关闭。

智能去除背景 可选 · 纯色 / 简单背景

可选步骤：选择 JPG / PNG / WebP 图片，自动去掉纯色或简单背景，生成透明 PNG 后再进入「八态单图」切割与对齐流程。仅适合白墙、绿幕、蓝幕等简单背景，无法处理发丝、毛发与半透明物体。

皮肤管理 查看 / 删除导入皮肤

内置皮肤不可删除。删除正在使用的导入皮肤时，会自动切回内置矢量皮肤；导入图片的体积会计入本地数据文件。

皮肤维护工具 检查 / 修复 / 逐状态替换 / 导出

维护工具直接编辑当前皮肤包的状态映射与图片资源：可逐状态替换、批量导入八态图片（文件名匹配 idle / drag / click / talk / sleep / work / happy / error）、清理未引用文件并导出备份。导出的 .deskpet-skin.zip 可重新导入到任意 DeskPet。

体型与层级

默认置顶且不占用任务栏；关闭置顶后宠物位于普通窗口层级，可能被其他窗口遮挡。低帧率模式通过离散化动画步进降低 CPU 占用，不影响交互反馈。

气泡与输入

语音朗读 FR-VOI-001 · TTS

使用 WebView2 内置 SpeechSynthesis 与系统语音包，不产生网络请求；每条 AI 回复也可单独点击 🔊 朗读。语音输入（ASR）尚未实现，将在后续版本接入本地运行时。

提醒与免打扰

时段内所有主动提醒静默排队，跨零点（如 22:00–08:00）同样生效；到点结束不补发历史搭话。
对我说「25 分钟后提醒我喝水」「每天 8:30 提醒我站会」即可创建；触发时宠物会跳出来播报，支持稍后 5 分钟。提醒由主进程调度器驱动。
实验性增强（默认关闭，不属于宠物核心能力）
这两项属于通用桌面助手能力，默认关闭；开启后全部在本地运行，不产生额外网络请求。

隐私与安全

零埋点 · 数据仅存本地 · 密钥不进入渲染层 · 出站域名公开披露（FR-SYS-003 / NFR-SEC-003 / NFR-PRV）

本地数据

出站域名披露 静态说明

仅在以下场景发起网络请求：① 对话 → 你配置的模型服务域名；② 天气 → geocoding-api.open-meteo.com、api.open-meteo.com；③ 联网搜索 → html.duckduckgo.com；④ 更新检查 → 默认 api.github.com 或你填写的清单地址。应用不提供逐请求审计表；本地日志已脱敏，不含密钥与对话内容。

工具能力与授权 FR-TOOL-001/003 / NFR-SEC-002

工具白名单在编译期固定：创建提醒、读取剪贴板、打开白名单链接、启动白名单应用、查询天气、联网搜索。天气与联网搜索默认拒绝，需在下方显式改为允许；不存在执行任意命令的通道（NFR-SEC-002）。

敏感能力

截图能力未启用。剪贴板仅在两种情况下被读取：你在「宠物与交互」中开启感知后由主进程比对变化（不保存、不上传），或你主动点击提示 / 模型调用 read_clipboard 且经你授权（NFR-PRV-003）。
