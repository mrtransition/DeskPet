人格管理

宠物与交互

皮肤 · 缩放 · 气泡行为 · 提醒与免打扰（FR-PET / FR-REM）

皮肤 FR-SKN-001 内置 3 套

导入后优先替代内置矢量形象，仍保留拖拽 / 点击 / 提醒等窗口交互；单文件建议不超过 1.5 MB。

体型与层级

默认置顶且不占用任务栏；关闭置顶后宠物位于普通窗口层级，可能被其他窗口遮挡。低帧率模式通过离散化动画步进降低 CPU 占用，不影响交互反馈。

气泡与输入

语音朗读 FR-VOI-001 · TTS

使用 WebView2 内置 SpeechSynthesis 与系统语音包，不产生网络请求；每条 AI 回复也可单独点击 🔊 朗读。语音输入（ASR）尚未实现，将在后续版本接入本地运行时。

提醒与免打扰

时段内所有主动提醒静默排队，跨零点（如 22:00–08:00）同样生效；到点结束不补发历史搭话。
对我说「25 分钟后提醒我喝水」「每天 8:30 提醒我站会」即可创建；触发时宠物会跳出来播报，支持稍后 5 分钟。提醒由主进程调度器驱动。

长期记忆

对我说「记住：xxx」即可写入；每次对话按相关度自动注入最多 5 条（FR-MEM-001/002/004）

上下文摘要 FR-MEM-003

超过阈值时，主进程调用当前模型把较早消息压缩成摘要；最近若干轮仍以原文发送。模型请求失败或返回空摘要时自动回退到轮数 / token 截断，不会阻断对话。

会话与数据

数据持久化于本地应用数据目录，不上传任何服务器（FR-DAT-004 / NFR-PRV）

会话历史 FR-DAT-002 检索 / 导出 Markdown

导入 / 导出

导出文件位于应用数据目录的 exports 文件夹（见导出后的提示路径）。

危险区 DR-003 二次确认

「重置全部数据」将同时清除供应商配置（含系统凭据管理器中的密钥）、人格、提醒与设置，并恢复宠物初始位置。

隐私与出站审计

零埋点 · 数据仅存本地 · 密钥不进入渲染层 · 出站请求可审计（FR-SYS-003 / NFR-SEC-003 / NFR-PRV）

本地数据

出站请求审计 仅域名 / 模型 / 状态 / 延迟

不记录密钥、请求头或对话内容。日志保存在内存中，退出即清空。

工具能力与授权 FR-TOOL-001/003 / NFR-SEC-002

工具白名单在编译期固定：创建提醒、读取剪贴板、打开白名单链接、启动白名单应用、查询天气、联网搜索。不存在执行任意命令的通道（NFR-SEC-002）。

敏感能力

截图能力未启用。剪贴板仅在两种情况下被读取：你在「宠物与交互」中开启感知后由主进程比对变化（不保存、不上传），或你主动点击提示 / 模型调用 read_clipboard 且经你授权（NFR-PRV-003）。

v2.1 新增了什么
  • 会话摘要压缩（FR-MEM-003）：超过阈值后由当前模型压缩较早消息，摘要作为上下文前缀；失败自动回退截断
  • TTS 朗读（FR-VOI-001 部分）：系统语音选择、语速调节、自动朗读与逐条重读，全程不联网
  • 低帧率模式（FR-PET-010）：工作 / 睡眠状态约 30fps，降低 CPU 占用
  • 结构化日志（NFR-MNT-001）：JSON Lines + 级别 + 密钥脱敏
v2.0 实现了什么
  • 真实系统能力：透明无边框置顶宠物窗口（置顶/任务栏可见性可配置）、独立气泡窗口（智能上下翻转 + 尾巴箭头 + 跟随移动 + 边缘拖拽调宽）、系统托盘（左键唤起 / 右键菜单）、全局快捷键（Ctrl+Shift+Space 唤起、Ctrl+, 设置）、开机自启、点击穿透、失焦自动关闭并恢复原前台窗口
  • 主进程对话：OpenAI / Anthropic / Gemini 三类流式协议适配、SSE 逐 token 推送、停止生成、非流式自动降级、超时/5xx 自动重试、429 冷却、上下文超长自动裁剪、错误分类；密钥存 Windows 凭据管理器，渲染层不可见，出站请求可在「隐私」页审计（FR-MDL-007/009/012/013、NFR-SEC-001/003）
  • v2.0 新增：工具调用闭环（函数调用 → 逐项授权 → 执行 → 结果回传 → 多轮续答，覆盖 OpenAI / Anthropic / Gemini 三协议）、皮肤包导入（zip：图集 + 状态机 + 提示音）、久坐/喝水提醒与免打扰时段、剪贴板感知、自动更新检查与手动安装、token 用量与费用估算、中英文界面切换
  • 其他功能：3 套人格 + 皮肤双向联动（含供应商绑定）、八态动画、拖拽与位置记忆、缩放、快捷动作、长期记忆注入、自然语言提醒（主进程调度器，支持一次性/每日/每周/间隔）、免打扰与补发、主动搭话、会话持久化/检索/导出、配置导入导出与 ID 重映射
