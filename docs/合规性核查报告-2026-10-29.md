# DeskPet 桌面版合规性核查报告

- 核查日期：2026-10-29
- 核查版本：v0.2.5
- 需求基准：`桌面 AI 宠物软件需求规格说明书（SRS）.md`（SRS-DESKPET-AI-001 v1.0）
- 核查范围：`deskpet-desktop/src-tauri/src/main.rs`、`src/*.html`、`src/shared.js`、`src/shared.css`、Tauri 配置与 capabilities

## 一、结论摘要

本轮核查以 **真实缺陷修复 + P0/P1 关键能力补齐** 为主，未引入 npm 依赖，保持 Tauri v2 + 零构建静态前端架构。

已修复的高风险问题包括：

1. 提醒调度重复触发 / 不落盘 / 重启丢失，重复提醒未按规则顺延。
2. 多窗口全量保存互相覆盖（宠物窗口或气泡窗口用旧快照覆盖设置）。
3. 状态文件非原子写入，异常退出可能损坏数据；旧版明文 API Key 残留。
4. 模型请求缺少超时、重试、429 冷却与上下文超长自动裁剪。
5. 气泡宽度拖拽、智能翻转、工作区夹紧与关闭后前台恢复不完整。
6. 设置页导入配置时供应商 / 人格 / 提醒引用未重映射或未走主进程命令。
7. 导出文件名可被路径穿越或 Windows 保留设备名利用。

新增 GIF / APNG / 动态 WebP 自定义动画形象，补足 FR-PET-009 的基本格式支持；完整皮肤包（图集 / 状态机 / 音效）仍未实现。

## 二、已修复缺陷明细

### 2.1 提醒与调度（FR-REM-001~004）

- 新增纯函数 `process_reminders`：重复提醒改为 **先触发、再顺延**，避免顺延后跳过本次触发。
- 支持 `daily`、`weekly`、`interval` 三类重复规则；一次性提醒触发后标记完成。
- 触发、顺延、禁用均写回状态文件并广播 `state-changed`，重启后不丢失。
- 调度线程每 5 秒调用 `ensure_pet_on_screen`，显示器拓扑变化后宠物自动回到可视工作区。
- `reminder_snooze` 增加 `content` 参数，稍后提醒保留原始提醒文案。
- 前端 `parseReminder` 支持「25 分钟后」「每天 8:30」「每周一 9:00」「每隔 2 小时」等表达。

### 2.2 多窗口状态一致性（NFR-REL-003、FR-DAT-001）

- 新增 `merge_state_snapshot`：非设置窗口保存时保留后端权威字段（缩放、穿透、拖拽、气泡宽度、任务栏、置顶、主动搭话、Enter 发送、每次点击新会话、低帧率等）。
- 任何窗口保存时，`reminders` 与 `petPos` 始终以后端为准，避免旧快照回滚提醒和位置。
- 设置窗口保存时同步 `S.settings` 后再调用后端命令，减少前后端字段漂移。

### 2.3 数据安全与持久化（FR-MDL-007、NFR-SEC-001、NFR-REL-002）

- 状态写入改为 **临时文件 + `.json.bak` 备份 + rename 原子替换**，并在 `file_lock` 下串行化。
- 主文件损坏时自动回退 `.json.bak`，原损坏文件保留为 `.corrupt-<ms>`。
- 启动时执行 `migrate_legacy_secrets`：清除旧版明文 `apiKey`，迁移至 Windows 凭据管理器。
- `export_text` 校验文件名：拒绝 `.` / `..`、控制字符、Windows 保留设备名与越界父目录。
- 主要状态锁使用 `unwrap_or_else(|e| e.into_inner())`，避免锁中毒导致进程崩溃。
- 新增隐私页出站审计：记录域名、协议类型、模型、状态码、结果与延迟；仅内存保存，可清空。

### 2.4 模型接入（FR-MDL-003、009、012、013）

- `ProvConf` 增加 `ctx_tokens` 与 `retry`，前端设置页同步暴露 `ctxTokens`。
- `run_chat` 按配置超时 / 重试；网络错误、超时与 5xx 指数退避；发送 `chat-notice` 让气泡显示状态。
- 400 且识别为上下文超长时自动裁剪并重试（最多 2 次）；429 透传 `Retry-After`，前端显示冷却倒计时。
- 流式响应增加空闲超时，避免连接挂死。
- 发送前按 `ctxTokens` 预算裁剪历史消息，与轮数上限先触发者生效。
- Azure OpenAI 使用 `api-key` 请求头与 `api-version=2024-02-01`；`provider_test` 对 Azure 改为最小 `chat/completions` 探测。

### 2.5 窗口、气泡与交互（FR-PET-004/005/007/008、FR-BUB-003/004/005/013）

- 气泡支持左右边缘拖拽调宽，范围 240–480 px；`finalize` 后重新居中并夹紧工作区。
- 气泡定位优先宠物上方，空间不足翻转下方，水平方向夹紧当前显示器工作区。
- 气泡高度 clamp 调整为 80–360 px，超出滚动。
- 提醒弹出使用 `show_bubble_reason("reminder")`，不抢当前前台焦点。
- `hide_bubble` 仅在实际可见时恢复前台窗口，避免误抢焦点。
- 宠物窗口按完整窗口尺寸夹紧；缩放后气泡跟随与右键菜单偏移修正。
- 设置页新增置顶、任务栏显示、气泡宽度开关/滑块，并在启动时应用。

### 2.6 设置与导入导出（FR-PSN-004、FR-DAT-002）

- 配置导出包含供应商、人格、设置、记忆、提醒，明确不含 API Key。
- 导入配置重新映射供应商 / 人格 ID，修正人格的 `providerId` 引用；导入的默认供应商会取代旧默认，避免多个 `isDefault`。
- 提醒不直接写入 `state_save`，而是逐条调用 `reminder_add`，防止被后端权威提醒列表覆盖。
- 导入后应用缩放、气泡宽度、穿透、免打扰、任务栏与置顶副作用。
- 人格与配置导入时校验皮肤键，非法值回退 `blue`。

### 2.7 前端健壮性与可访问性（NFR-UI-002、NFR-CON-003）

- 全局 `error` / `unhandledrejection` 兜底，避免渲染层异常静默失败。
- 代码块轻量语法高亮、一键复制；Markdown 渲染保留。
- 支持 `prefers-reduced-motion` 与 `prefers-contrast`。
- 气泡上下文裁剪同时提示轮数截断与 token 截断。
- 新增 GIF / APNG / 动态 WebP 自定义形象导入（≤ 1.5 MB），保留拖拽、点击、睡眠、提醒动画；可一键恢复内置矢量皮肤。
