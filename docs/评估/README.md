# 评估报告

本目录存放 P2 审慎评估类工作包的结论，用于把“是否要做”与“做到什么边界”固定下来，避免以“顺手支持”的方式引入功能或平台。

| 编号 | 工作包 | 结论 | 报告 |
|---|---|---|---|
| P-13 | 受限技能系统评估 | 暂不引入技能运行时；未来仅接受声明式、无代码、动作映射到编译期白名单的形态 | [受限技能系统评估](受限技能系统评估.md) |
| P-14 | 跨平台审慎评估 | 短期维持 Windows 优先，不启动 macOS / Linux 移植；满足全部触发条件后再单独立项 | [跨平台评估](跨平台评估.md) |

评估报告不替代安全评审：若评估结论导致新增工具、感知源或系统集成点，仍须按[安全评审流程](../治理/安全评审流程.md)建立 `INT-xxx` 记录。
