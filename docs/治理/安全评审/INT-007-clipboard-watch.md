## 1. 能力概述

用户显式开启后，主进程定时读取剪贴板纯文本并与上次内容比对；发现变化时在宠物旁给出“点我处理”的预览提示。用于把刚复制的内容快速带入聊天。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 剪贴板纯文本，最多保留 2000 字符用于比对 |
| 是否离开本机 | 否 |
| 发送目的地 | 仅本地宠物窗口（80 字符以内预览） |
| 是否进入模型上下文 | **否**，除非用户点击提示后主动发送 |
| 是否落盘 | 否（仅内存中的 `clipboard_last`） |
| 是否写日志 | 否 |

## 3. 权限范围

- 仅读取纯文本；
- 不读取图片、文件、HTML 或富文本；
- 不监听键盘、不注入其他进程；
- 仅在设置开启且非免打扰时运行。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | 关闭 |
| 开启方式 | 设置 → 宠物与交互 → 剪贴板感知 |
| 是否可记忆 | 不适用（本身就是持久开关） |
| 撤销位置 | 同一设置项 |
| 撤销生效 | 立即；下一轮检测不再读取 |
| 关闭后行为 | 不读取剪贴板；已显示提示自然消失 |

## 5. 日志与审计

- 不记录剪贴板内容或预览；
- 不记录检测频率；
- 用户可通过设置页确认开关状态。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 剪贴板为空 / 非文本 | 跳过 |
| 内容不足 4 字符 | 跳过 |
| 与上次相同 | 跳过 |
| 读取失败 | 静默跳过，不影响聊天 |
| 免打扰中 | 不读取 |

## 7. 风险评级

- 等级：中
- 理由：持续读取剪贴板可能接触到密码、验证码、私密文本；虽然不上传、不落盘，但本地预览仍可能被旁人看到；
- 滥用场景：用户误开后长期运行。缓解：默认关闭、折叠入口、仅本地、可随时关闭。

## 8. 防线清单

- [x] 默认关闭
- [x] 仅纯文本、长度上限
- [x] 不上传、不落盘、不写日志
- [x] 仅本地预览，点击后才进入聊天
- [x] 免打扰时不读取
- [x] 一键关闭
- [ ] 未提供“按应用排除”或“敏感内容自动忽略”（记录为后续改进）

## 9. 结论

🟡 条件通过：

1. 必须保持默认关闭；
2. 不得自动把内容发送给模型；
3. 不得增加剪贴板历史或持久化；
4. 后续可评估敏感内容识别（如疑似密码 / 验证码）并跳过提示，但不作为本版本前置条件。

## 10. 验证与复审

- 手工验收：开启后复制一段文本 → 宠物出现预览提示 → 点击才进入聊天；关闭后复制不再提示；
- 检查 `deskpet.log` 无剪贴板内容；
- 复审触发：增加历史、自动发送、图片 / 文件支持、按应用过滤。
