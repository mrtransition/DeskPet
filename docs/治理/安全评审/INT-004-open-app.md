## 1. 能力概述

模型经用户授权后启动白名单内的本地应用（记事本、计算器、画图、资源管理器、截图工具），用于“帮我打开计算器”等轻量桌面辅助。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 模型给出的应用名 |
| 是否离开本机 | 否 |
| 发送目的地 | 本地进程（固定可执行文件） |
| 是否进入模型上下文 | 仅回传“已启动 <app>” |
| 是否落盘 | 否 |
| 是否写日志 | 否 |

## 3. 权限范围

- 编译期固定五个目标：`notepad` / `calc` / `mspaint` / `explorer` / `snippingtool`（含中文别名）；
- 只按固定可执行文件名启动，不接收参数、路径、环境变量或命令行；
- 不经过 shell，不拼接用户输入；
- 不请求管理员权限。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | 询问 |
| 首次调用 | 授权卡片显示应用名与“仅本地”标识 |
| 是否可记忆 | 是 |
| 撤销位置 | 设置 → 工具能力与授权 |
| 撤销生效 | 立即 |
| 关闭后行为 | 不再启动应用 |

## 5. 日志与审计

- 不记录启动参数（本来也没有参数）；
- 气泡显示“已启动 <app>”摘要；
- 不跟踪被启动应用的后续行为。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 用户拒绝 / 超时 | 不启动 |
| 应用不在白名单 | 返回错误，列出允许的应用 |
| 可执行文件不存在 / 启动失败 | 返回错误，不尝试替代命令 |

## 7. 风险评级

- 等级：中
- 理由：启动本地进程会改变用户桌面状态，且资源管理器可能暴露文件系统；但目标固定、无参数注入面；
- 滥用场景：反复启动应用造成骚扰；利用 `explorer` 打开任意路径（当前无法传参，风险受控）。

## 9. 结论

🟡 条件通过：

1. 白名单只增不减需重新评审；不得加入浏览器、终端、脚本宿主、包管理器；

3. 若未来需要“打开指定文件”，应作为独立能力评审，不能复用本工具。

## 10. 验证与复审

- 手工验收：让模型打开 `notepad` → 授权 → 记事本启动；让模型打开 `powershell` → 应被拒绝；
- 复审触发：新增应用、增加参数、改变启动方式。
