## 1. 能力概述

模型经用户放行后，用 DuckDuckGo HTML 页面做一次网页搜索，返回最多 5 条标题与链接，用于“帮我查一下……”等聊天场景。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 模型给出的搜索关键词 |
| 是否离开本机 | 是 |
| 发送目的地 | `html.duckduckgo.com` |
| 是否进入模型上下文 | 是：结果标题与链接会回传模型 |
| 是否落盘 | 否 |
| 是否写日志 | 出站日志记录域名、状态、延迟，不记录关键词 |

## 3. 权限范围

- 仅访问 `html.duckduckgo.com`；
- 请求超时 12 秒；
- 固定 User-Agent，不附加设备指纹；
- 只解析标题与链接，不下载目标网页内容；
- 不跟随搜索结果中的链接。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | **拒绝**（`toolSettings.auth.web_search = "deny"`） |
| 首次调用 | 默认直接拒绝；需用户先在设置页放行 |
| 是否可记忆 | 是 |
| 撤销位置 | 设置 → 工具能力与授权 |
| 撤销生效 | 立即 |
| 关闭后行为 | 不再发起搜索请求 |

## 5. 日志与审计

- 出站日志只记录域名、状态、延迟；
- 不记录搜索词、结果标题或链接；
- 气泡显示“找到 N 条结果”摘要。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 用户拒绝 / 超时 | 不请求 |
| 关键词为空 | 返回错误 |
| 网络失败 / 超时 | 返回错误，不切换搜索引擎 |
| 页面结构变化 | 返回 0 条结果，不猜测解析 |
| 结果链接非 http(s) | 丢弃该条 |

## 7. 风险评级

- 等级：中
- 理由：搜索关键词可能包含敏感信息并发送给第三方；结果可能含误导或恶意链接（但不会自动打开）；
- 滥用场景：高频搜索、通过关键词外带信息。缓解：默认拒绝、逐次授权、固定域名、结果数量上限。

## 8. 防线清单

- [x] 默认拒绝
- [x] 逐次授权 + 出站标识
- [x] 超时与结果数量上限
- [x] 不自动打开结果链接

## 9. 结论

🟡 条件通过：

1. 默认必须保持“拒绝”；
2. 不得加入后台自动搜索、搜索历史或个性化；
3. 不得自动抓取结果页正文或绕过目标站点限制；
4. 若接入正式搜索 API，需重新评审密钥管理、发送字段与计费。

## 10. 验证与复审

- 手工验收：默认状态下让模型搜索 → 应被拒绝；放行后 → 授权卡片标“会出站” → 返回最多 5 条结果；
- 检查日志无搜索关键词；
- 复审触发：更换搜索源、增加自动抓取、增加搜索历史。
