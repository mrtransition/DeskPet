## 1. 说明

本表是所有工具、感知源、系统集成点与外部输入解析的**评审索引**。新增记录时：

1. 从 `_模板.md` 复制并填写；
2. 编号取当前最大序号 + 1，不复用；
3. 在本表追加一行，状态与结论必须与记录正文一致；
4. 能力移除时保留记录，状态改为“已移除”，不要删除。
