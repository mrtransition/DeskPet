## 1. 能力概述

模型经用户授权后读取当前剪贴板纯文本，用于“帮我总结刚复制的内容”等聊天辅助场景。属于敏感本地读取能力。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 剪贴板中的纯文本，最多 8000 字符（默认 2000） |
| 是否离开本机 | 是：作为工具结果回传给用户配置的模型服务 |
| 发送目的地 | 当前会话使用的模型端点 |
| 是否进入模型上下文 | 是（这是能力的目的） |
| 是否落盘 | 否；不写入 `data.json`、不写日志 |
| 是否写日志 | 否（仅气泡显示“读取到 N 个字符”） |

## 3. 权限范围

- 仅读取纯文本；不读取图片、文件列表、HTML、富文本；
- 不监听剪贴板变化（那是独立的剪贴板感知能力，见 INT-007）；
- 不访问文件系统或网络（网络请求由模型调用本身产生）。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | 询问 |
| 首次调用 | 授权卡片明确说明“内容会作为工具结果发回模型”与“仅本地读取，但结果会出站” |
| 是否可记忆 | 是；建议用户在理解出站影响后再选择“始终允许” |
| 撤销位置 | 设置 → 隐私 → 工具能力与授权 |
| 撤销生效 | 立即 |
| 关闭后行为 | 工具不可用；不会后台读取剪贴板 |

## 5. 日志与审计

- 不记录剪贴板内容；
- 不记录长度以外的元数据；
- 用户可在气泡工具卡片看到读取摘要。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 用户拒绝 / 超时 | 不读取，回传“未授权，已跳过” |
| 剪贴板为空或非文本 | 返回错误，不上传空内容 |
| 内容超长 | 按 `max_chars` 截断，并标记 `truncated` |
| 系统剪贴板不可用 | 返回错误，不重试 |

## 7. 风险评级

- 等级：中
- 理由：剪贴板可能包含密码、验证码、私密文本；读取后会进入模型上下文并出站；
- 滥用场景：诱导用户授权后批量外带剪贴板内容。缓解：逐次授权、内容预览、默认不记忆、可撤销。

## 9. 结论

🟡 条件通过：

1. 默认必须保持“询问”，不得改为“始终允许”；
2. 授权卡片必须持续展示“结果会发回模型”的说明；
3. 不增加后台定时读取或自动发送；
4. 若未来支持图片 / 文件剪贴板，需重新评审。

## 10. 验证与复审

- 手工验收：复制一段文本 → 让模型调用 → 授权卡片含出站提示 → 允许后返回截断内容；
- 检查 `deskpet.log` 不含剪贴板正文；
- 复审触发：支持富文本 / 图片、增加自动读取、改变默认授权。
