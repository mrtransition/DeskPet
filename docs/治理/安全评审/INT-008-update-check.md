## 1. 能力概述

检查 GitHub Releases（默认）或用户自定义清单，比较版本号；有更新时提示说明与下载地址，由用户确认后下载到本地 `exports/`，**不静默安装、不自动运行**。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 版本号、更新说明、下载地址 |
| 是否离开本机 | 是 |
| 发送目的地 | `api.github.com`（默认）或用户填写的清单地址；下载地址由清单提供 |
| 是否进入模型上下文 | 否 |
| 是否落盘 | 是：用户确认下载后保存到 `exports/` |
| 是否写日志 | 是：`update.downloaded` 记录字节数；不记录 URL 参数 |

## 3. 权限范围

- 仅 HTTPS（非 HTTPS 清单 / 下载地址不采信）；
- 默认清单：`https://api.github.com/repos/mrtransition/DeskPet/releases/latest`；
- 解析 GitHub Releases API（`tag_name` / `body` / `assets[]`）与自定义最小清单（`version` / `notes` / `url`）；
- 下载地址优先 `.zip`，其次 `.exe`；排除 API 自我引用 URL；
- 不执行下载的文件，不修改系统，不写注册表。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | 自动检查 **关闭**；手动检查不受限 |
| 开启方式 | 设置 → 关于 → 启动时自动检查更新 |
| 是否可记忆 | 是（设置项） |
| 撤销位置 | 同一设置项 |
| 撤销生效 | 立即；下次启动不再请求 |
| 关闭后行为 | 无后台更新请求；手动检查仍可用 |

## 5. 日志与审计

- 记录 `update.downloaded` 与字节数；
- 出站日志记录主机、状态、延迟；
- 不记录完整下载 URL、不记录响应正文。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 清单请求失败 | 提示检查失败，保留当前版本，不阻断启动 |
| 清单格式不识别 | 明确提示缺少 `version` 或 `tag_name` |
| 下载地址非 HTTPS | 不采信 |
| 下载失败 / 中断 | 提示失败，不保留半截文件作为可执行产物 |
| 用户取消 | 不下载、不安装 |

## 7. 风险评级

- 等级：中
- 理由：更新链路是供应链攻击的高价值目标；当前只校验 HTTPS，未做签名 / 哈希；
- 滥用场景：篡改发布产物、DNS / 代理劫持、伪造自定义清单。缓解：HTTPS、只下载不执行、用户手动确认、来源可见。

## 9. 结论

🟡 条件通过：

1. 在 NFR-SEC-004 完成前，不得开启静默下载或自动安装；
2. 发布说明必须持续披露“更新签名未实现”；
3. 自定义清单地址必须由用户显式填写，不提供远程下发；
4. 完成签名后需重新评审密钥管理与失败回退。

## 10. 验证与复审

- 手工验收：点击检查更新 → 显示版本比较结果；确认下载 → 文件出现在 `exports/` 且未自动运行；
- 复审触发：实现签名、改为自动安装、切换更新源、增加增量更新。
