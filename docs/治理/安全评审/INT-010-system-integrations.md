## 1. 能力概述

DeskPet 作为桌面常驻应用，需要四项基础系统集成：

1. 托盘图标与菜单（左键唤起气泡，右键完整菜单）；
2. 全局快捷键 `Ctrl+Shift+Space`（被占用时自动降级）；
3. 开机自启（用户显式开启，当前用户级自启动项）；
4. 单实例运行（Windows 命名互斥量 + 命名事件）。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 快捷键事件、托盘点击、启动参数 |
| 是否离开本机 | 否 |
| 发送目的地 | 仅应用内部窗口 |
| 是否进入模型上下文 | 否 |
| 是否落盘 | 开机自启状态由系统管理；单实例不落盘 |
| 是否写日志 | 单实例唤起记录 `app.second_launch` |

## 3. 权限范围

- 托盘：无额外权限，仅当前用户会话；
- 全局快捷键：注册一个组合键，不监听其他按键，不做键盘记录；
- 开机自启：仅在用户显式开启时写入当前用户自启动项，不请求管理员权限；
- 单实例：创建 `Local\DeskPet-SingleInstance-com.mrtransition.deskpet` 命名互斥量与命名事件，作用域为当前会话。

## 4. 授权与撤销

| 能力 | 默认 | 开启 / 撤销 | 生效 |
|---|---|---|---|
| 托盘 | 开启 | 退出应用 | 立即 |
| 全局快捷键 | 注册（冲突则降级） | 不使用；无独立开关 | 立即 |
| 开机自启 | 关闭 | 托盘菜单 / 设置 | 立即写入 / 移除自启动项 |
| 单实例 | 开启 | 无（结构约束） | 始终 |

## 5. 日志与审计

- 单实例唤起写 `app.second_launch`；
- 启动完成写 `app.started`；
- 不记录快捷键内容、托盘点击序列或用户输入。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 快捷键被占用 | 自动降级，不阻断启动 |
| 托盘创建失败 | 记录警告，宠物窗口仍可用 |
| 自启动项写入失败 | 设置页反馈失败，不重试提权 |
| 互斥量已存在 | 唤起首个实例后退出，退出码 0 |
| 命名事件失败 | 退化为仅互斥量判定，不产生第二套调度器 |

## 7. 风险评级

- 等级：低
- 理由：均为本地、用户可见、可撤销的系统集成，不读取敏感数据、不联网；
- 滥用场景：全局快捷键冲突、自启动被误开。缓解：冲突降级、默认关闭、系统设置可撤销。
