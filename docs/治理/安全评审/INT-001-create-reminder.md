## 1. 能力概述

模型根据用户自然语言创建本地定时提醒（一次 / 每日 / 每周 / 间隔），是“聊天助手”向桌面场景的自然延伸。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 模型给出的提醒内容、相对分钟数 / `HH:MM`、重复规则、间隔 |
| 是否离开本机 | 否 |
| 发送目的地 | 仅本地提醒调度器 |
| 是否进入模型上下文 | 执行结果摘要会回传模型（提醒内容本身来自模型） |
| 是否落盘 | 是，`data.json` 的 `reminders` 数组 |
| 是否写日志 | 不单独记录提醒内容 |

## 3. 权限范围

- 无系统权限，不访问文件系统、网络或其他进程；
- 参数边界：内容截断 60 字符；相对时间 0.1 分钟 ~ 7 天；间隔 1 ~ 10080 分钟；重复规则限定四种枚举；
- 不接受脚本、命令、回调地址或任意字段。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | 询问 |
| 首次调用 | 弹出授权卡片，显示参数预览 |
| 是否可记忆 | 是（始终允许 / 始终拒绝） |
| 撤销位置 | 设置 → 隐私 → 工具能力与授权 |
| 撤销生效 | 立即；改回“每次询问”后下次调用重新弹卡 |
| 关闭后行为 | 不再创建提醒；已有提醒保留，可手动删除 |

## 5. 日志与审计

- 不记录提醒正文；
- 气泡内显示“已创建提醒：<内容>”摘要；
- 数据文件可随时查看与编辑。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 用户拒绝 / 超时 | 不创建，回传“未授权，已跳过” |
| 内容为空 | 返回错误，不创建 |
| 时间参数非法 | 回退到默认 25 分钟或按枚举兜底，不执行任意动作 |
| 写盘失败 | 提醒仅存在于内存，下次保存时重试；不影响应用运行 |

## 7. 风险评级

- 等级：低
- 理由：仅写本地列表，无外部副作用，参数域极窄；
- 滥用场景：大量创建提醒造成骚扰。当前无速率限制，但每轮工具调用上限 4 轮，影响有限。
