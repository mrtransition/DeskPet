## 1. 能力概述

模型经用户授权后，用系统默认浏览器打开一个链接；域名必须命中用户可维护的白名单。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 模型给出的 URL |
| 是否离开本机 | 是：交给系统浏览器访问 |
| 发送目的地 | URL 所在网站（由浏览器发起，DeskPet 不代理） |
| 是否进入模型上下文 | 仅回传“已打开 <url>” |
| 是否落盘 | 否 |
| 是否写日志 | 否 |

## 3. 权限范围

- 仅 `http` / `https`；拒绝 `file:`、`javascript:`、`data:` 等协议；
- 域名匹配：完全相等或以 `.白名单域名` 结尾，忽略 `www.` 前缀；
- 白名单默认：`github.com`、`developer.mozilla.org`、`bing.com`、`baidu.com`、`wikipedia.org`；
- 用户可在设置页增删域名；不在白名单的域名直接拒绝；
- 不拼接命令行，不经过 shell。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | 询问 |
| 首次调用 | 授权卡片显示 URL 预览与“会出站”标识 |
| 是否可记忆 | 是 |
| 撤销位置 | 工具授权 + 域名白名单 |
| 撤销生效 | 立即 |
| 关闭后行为 | 不再打开任何链接 |

## 5. 日志与审计

- 不记录完整 URL；
- 气泡显示“已打开 <url>”摘要，供用户即时核对；
- 白名单变更立即写入设置。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 用户拒绝 / 超时 | 不打开 |
| URL 解析失败 / 协议非法 | 返回错误 |
| 域名不在白名单 | 返回错误并提示到设置页添加 |
| 系统浏览器启动失败 | 返回错误，不回退到应用内加载 |

## 7. 风险评级

- 等级：中
- 理由：可诱导用户打开钓鱼站点；虽然不自动加载内容，但浏览器会发起真实请求；
- 滥用场景：模型幻觉生成恶意链接、利用白名单子域匹配打开非预期站点。缓解：白名单、逐次授权、域名可见、无自动打开。

## 8. 防线清单

- [x] 协议白名单
- [x] 域名白名单 + 子域匹配规则
- [x] 逐次授权 + 出站标识
- [x] 不在应用内加载网页
- [x] 失败关闭
- [x] 用户可维护域名列表
- [x] 默认白名单只含常用可信站点

## 9. 结论

🟡 条件通过：

1. 默认白名单不得加入短链、网盘、可执行文件下载站；
2. 不增加“应用内浏览器”或自动下载；
3. 不根据模型输出自动扩写白名单；
4. 若未来支持自定义协议或本地文件链接，需重新评审。

## 10. 验证与复审

- 测试：`host_allowed()` 覆盖 `www.`、子域、大小写与空白名单；
- 手工验收：让模型打开非白名单域名 → 应被拒绝并提示；白名单域名 → 授权后由默认浏览器打开；
- 复审触发：白名单匹配规则变化、支持新协议、应用内打开。
