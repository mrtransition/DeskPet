## 1. 能力概述

在设置 → 宠物与交互 → 体型与层级提供「关闭硬件加速」开关。开启后，DeskPet 在**下次启动时**于 WebView2 创建前向 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 追加固定的 `--disable-gpu`，让界面改由 CPU 渲染，用于缓解部分显卡驱动导致的闪烁、黑屏或透明区域花屏。它不参与聊天链路，也不改变任何模型调用。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 仅 `data.json` 中的布尔值 `settings.disableGpu`；不读取硬件型号、显卡驱动或系统信息 |
| 数据是否离开本机 | 否 |
| 发送到哪里（域名 / 进程） | 仅传给本机 WebView2 运行时（环境变量），不联网 |
| 是否进入模型上下文 | 否 |
| 是否落盘（文件 / 位置 / 保留时间） | 仅随原有 `data.json` 持久化一个布尔值，随用户数据保留 |
| 是否写入日志 | 是：启动时写 `perf.gpu_disabled`（事件 + 固定说明），不含硬件标识 |

## 3. 权限范围

- 需要的系统权限：无新增；复用当前进程已有的环境变量与 WebView2 启动能力。
- 是否可用更小权限完成：已是当前可实现的最小方式（WebView2 不提供进程内关闭 GPU 的公开 API）。
- 是否涉及管理员权限 / 提权：否。
- 访问边界：只读取 `%APPDATA%\com.mrtransition.deskpet\data.json` 的一个布尔值；参数值在代码中写死为 `--disable-gpu`，不接受用户或远程输入。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | **关闭**（保持硬件加速） |
| 首次调用行为 | 用户手动勾选后保存；不弹窗、不自动开启 |
| 是否可记忆 | 是（`settings.disableGpu`） |
| 用户在哪里撤销 | 同一设置项取消勾选 |
| 撤销是否立即生效 | 下次启动生效；当前进程渲染方式不变 |
| 关闭后是否仍有后台行为 | 否；关闭后启动不再注入 `--disable-gpu` |

## 5. 日志与审计

- 记录的事件：`perf.gpu_disabled`（仅在开关为开启时写入）。
- 是否包含敏感内容（密钥 / 对话 / 剪贴板 / 文件内容）：否。
- 用户能否查看与清除：可查看（应用日志区），可随日志清理一并删除。
- 脱敏方式：只写固定文案，不记录环境变量原文、显卡型号或其他机器信息。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| `data.json` 不存在 / 不可读 | 视为关闭，保持默认硬件加速，不阻断启动 |
| `data.json` 解析失败 | 视为关闭；正常启动流程仍按既有损坏回退逻辑处理 |
| 系统已有 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` | 保留已有参数并追加固定值，不覆盖、不重复追加 |
| 重复启动 / 已有实例 | 单实例逻辑生效，不重复初始化 WebView2，也不叠加参数 |
| WebView2 运行时不支持该参数 | 由运行时忽略；应用照常启动，仅可能不改变渲染方式 |
| 用户关闭开关 | 下次启动不再注入，恢复硬件加速 |

原则：失败关闭（fail closed）。读取失败时保持默认（加速开启），不猜测用户意图，也不扩大参数范围。

## 7. 风险评级

- 等级：低
- 理由：不联网、不新增系统权限、不读取或外传数据；可写参数在编译期固定，仅能追加一个布尔开关。
- 主要滥用场景：若实现把环境变量或设置值当作任意参数拼接，可能注入其他 WebView2 开关。现有缓解：参数值硬编码、仅做去重追加、读取失败即回退默认。
- 现有缓解措施：单实例；启动前一次性读取；不写回、不迁移；单元测试覆盖默认值与参数合并。

## 9. 结论与前置条件

✅ 通过。

前置条件（后续版本不得破坏）：

1. 注入的参数必须保持编译期常量，禁止把设置值或远程配置当作任意 WebView2 参数使用；
2. 必须保留用户 / 系统已有 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS`，只追加、不覆盖；
3. 默认值必须保持「硬件加速开启」，不得因兼容个别环境而默认关闭；
4. 读取 `data.json` 失败时保持默认，不影响启动主流程；
5. 不得为该能力引入网络请求、硬件信息采集或额外系统权限。

需要同步更新的文档：发布说明安全小节、[《硬件加速与显卡兼容》](../../硬件加速与显卡兼容.md)、ROADMAP 已完成项、SRS 实现状态表。
