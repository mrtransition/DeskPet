## 1. 能力概述

用户显式开启后，主进程按固定节拍（约 15 分钟）依据**本机时间**生成一条轻量情境搭话，例如午间提醒吃饭、晚间提醒休息。用于验证「情境感知陪伴」是否可以克制地提升陪伴感，不接入窗口标题、键盘、应用列表或任何外部服务。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 本机时间（UTC+8 当天分钟数）、气泡窗口是否可见、用户是否在宠物窗口有最近操作（仅前端内存） |
| 数据是否离开本机 | 否 |
| 发送到哪里（域名 / 进程） | 主进程 → 宠物窗口 WebView（本地 IPC） |
| 是否进入模型上下文 | 否 |
| 是否落盘（文件 / 位置 / 保留时间） | 仅设置项 `settings.context` 落盘；不保存搭话内容 |
| 是否写入日志 | 否 |

## 3. 权限范围

- 需要的系统权限：无（不申请新权限）；
- 是否可用更小权限完成：是，仅使用系统时钟；
- 是否涉及管理员权限 / 提权：否；
- 访问边界：只读取小时级时间，不读取时区数据库、定位、网络或进程信息。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | 关闭（`enabled: false`） |
| 首次调用行为 | 不运行；用户需在「宠物与交互 → 情境陪伴」勾选开启 |
| 是否可记忆 | 是，三个开关持久化 |
| 用户在哪里撤销 | 同一设置区；或点击宠物旁的「情境」徽标直接打开设置 |
| 撤销是否立即生效 | 是，下一轮调度即不再产生情境搭话 |
| 关闭后是否仍有后台行为 | 否 |

## 5. 日志与审计

- 记录的事件：无；
- 是否包含敏感内容：否；
- 用户能否查看与清除：设置页可查看开关状态并随时关闭；
- 脱敏方式：不适用（不写日志）。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 用户关闭总开关 | 不产生任何情境搭话 |
| 免打扰 / 时段外 | 不产生 |
| 气泡已打开 | 跳过，避免打断当前对话 |
| 用户近期有操作且勾选「仅闲置时」 | 前端丢弃该次提示 |
| 时间解析异常 | 使用保守的时段回退，不抛出错误 |

原则：失败关闭（fail closed），不降级为“尽力打扰”。

## 7. 风险评级

- 等级：低
- 理由：只使用本机时间，不采集行为数据，不出站；
- 主要滥用场景：用户误开后觉得打扰。缓解：默认关闭、约 15 分钟节拍、35% 概率跳过、免打扰与时段窗口、点击徽标一键关闭；
- 现有缓解措施：无网络请求、无持久化内容、可在设置页撤销。
