## 1. 能力概述

用户从本地选择 `.deskpet-skin.zip` 或 4×2 八态单图导入皮肤；主进程解析压缩包、校验清单、切割图片、写入 `skins/*.json` 并在宠物窗口渲染。当前不再提供单张图片与 Codex 宠物导入入口。

## 2. 数据流向

| 问题 | 回答 |
|---|---|
| 读取数据 | 用户选择的 zip / 图片文件 |
| 是否离开本机 | 否 |
| 发送目的地 | 仅本地文件系统与应用数据目录 |
| 是否进入模型上下文 | 否 |
| 是否落盘 | 是：`skins/<id>.json`、`skins/current.json` |
| 是否写日志 | 仅记录资源外置事件，不记录图片内容 |

## 3. 权限范围

- 只读取用户通过文件选择器指定的文件；
- 压缩包限制：zip ≤ 128 MB、单文件 ≤ 64 MB、解压总计 ≤ 256 MB、条目 ≤ 200；
- 拒绝路径穿越（`..`、绝对路径）与压缩炸弹；
- 只接受声明的图片 / 音效类型；SVG 拒绝脚本、外链图片与事件属性；
- 不联网、不执行包内任何代码。

## 4. 授权与撤销

| 项 | 内容 |
|---|---|
| 默认状态 | 不适用（用户主动导入才发生） |
| 首次调用 | 文件选择器 + 导入结果提示 |
| 是否可记忆 | 不适用 |
| 撤销位置 | 设置 → 皮肤 → 删除导入皮肤 |
| 撤销生效 | 立即；未引用资源在下次保存 / 启动时清理 |
| 关闭后行为 | 不再使用该皮肤资源 |

## 5. 日志与审计

- 不记录图片内容、文件名或用户路径；
- 导入失败时返回明确原因（格式、尺寸、条目数、路径非法）；
- 皮肤管理页可查看 / 切换 / 删除导入皮肤。

## 6. 失败降级

| 场景 | 行为 |
|---|---|
| 非 zip / 非图片 | 拒绝并提示正确入口 |
| 路径穿越 / 绝对路径 | 拒绝整个包 |
| 超过大小 / 条目限制 | 拒绝整个包 |
| 清单字段缺失 / 状态映射非法 | 拒绝并提示 |
| 图片解码失败 | 拒绝该文件，不写入半成品 |
| SVG 含脚本 / 外链 | 拒绝该资源 |

## 7. 风险评级

- 等级：中
- 理由：解析不可信外部文件是典型攻击面（压缩炸弹、路径穿越、解码漏洞、SVG XSS）；
- 滥用场景：恶意皮肤包耗尽磁盘 / 内存、写入任意路径、通过 SVG 执行脚本。缓解：大小与条目上限、路径校验、SVG 清洗、渲染层 CSP。

## 9. 结论

🟡 条件通过：

1. 不恢复单张图片与 Codex 宠物的导入入口，除非重新评审；
2. 不引入可从网络直接下载并安装皮肤的通道；
3. 新增图片格式（如 AVIF）或动画运行时需重新评审解码库与体积；
4. 保持“导入失败不产生半成品”的原子性。
