# DeskPet 社区画廊（MVP）

这是 P-12 的低成本静态画廊：**没有后端、没有账号、没有埋点**，只维护一个
[`gallery.json`](gallery.json) 与一个静态页面 [`index.html`](index.html)。

## 收录范围

- 仓库内可验证的示例皮肤包 / 人格；
- 有明确许可证、可复现打包步骤的社区作品；
- 不收录需要额外联网服务、可执行脚本或闭源二进制的内容。

## 如何提交作品

1. 按 [皮肤与图集规范](../皮肤与图集规范.md) 打包 `.deskpet-skin.zip`；
2. 提供一张预览图（建议 ≤ 512 KB）与作者署名、许可证；
3. 在 `gallery.json` 的 `items` 中追加条目（`id` 唯一）；
4. 在 PR 描述中附上导入 / 切换的验证步骤。

人格作品可直接导出 JSON，并在描述中写明 `animation` 与 `memoryTags`。

## 本地预览

画廊页面只依赖相对路径。直接双击 `index.html` 即可查看内置条目；
若浏览器限制本地文件读取，可用任意静态服务器：

```powershell
python -m http.server 8080 --directory docs/gallery
```

## 维护边界

- 画廊是**展示与推荐**，不提供自动下载安装、评分、评论或用户上传；
- 不在应用内新增网络请求；应用内「关于」页只提供本页面的 GitHub 链接；
- 条目失效或与当前皮肤规范不兼容时，直接从 `gallery.json` 移除并保留 Git 历史。
