# DeskPet 后续开发路线图

> 基线版本：v2.2.1（2026-11-11）
> 需求依据：[SRS v1.2](../桌面%20AI%20宠物软件需求规格说明书（SRS）.md)
> 维护方式：每个里程碑完成后更新状态、验收结果与版本号。

## 1. 现状判断

v2.2.0 已覆盖 SRS 的大部分核心功能，并补齐了 i18n、右键菜单、宠物交互状态、单实例、首次引导与渲染层 CSP；但按 v1.1 的 P0/P1 口径，仍有若干“已宣称完成、实际部分交付”的项和工程基础缺口。剩余工作集中在三类：

1. **P0/P1 名实不符项**（备份恢复、会话批量管理、提醒补发等）；
2. **体验与合规缺口**（更新签名、无障碍、硬件加速、日志轮转）；
3. **工程化与数据层升级**（SQLite/FTS、安装器、模块化、CI）。

当前最值得优先处理的不是继续堆新功能，而是先补齐 v1 验收基线中的 P0/P1 缺口，再进入多模态与跨平台阶段。P2 不阻塞发布，P3 仅登记不排期。

## 4. 建议执行顺序

如果只做一轮，建议按以下顺序：

1. ~~**单实例 + 首次引导**~~ — ✅ v2.2.0 已关闭；
2. ~~**CSP + 隐私披露**~~ — CSP 已随 v2.2.0 关闭，隐私披露（引导页第三步）待补入验收；
3. **更新签名与失败回退** — 安全项，避免篡改与更新阻断；
4. **备份恢复 + 会话批量管理** — 数据安全与可用性；
5. **i18n 回归检查** — v2.1.3 已补全，v2.2 做英文界面无中文残留自动检查；
