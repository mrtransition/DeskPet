# v2.3.0 — 智能去除背景与皮肤导入入口收敛

> 发布日期：2026-11-12
> 基线：v2.2.1
> 归档说明：本文件于 2026-11-13 按《发布说明规范》回溯补全；功能内容与 v2.3.0 实际发布一致，结构与“收敛与移除”章节为治理基线补录。
> 对应提交：`2c73dae`（chore(release): v2.3.0 智能去除背景与皮肤导入入口收敛）

## 摘要

本版本新增纯前端的“智能去除背景”，让用户可以把纯色 / 绿幕 / 蓝幕图片处理成透明 PNG，再进入八态单图切割；同时把皮肤导入入口收敛为「八态单图」与「皮肤包」两条路径，减少重复入口与维护成本。皮肤图片与音效改为外置存储，`data.json` 不再随每次保存搬运十几 MB 资源。

## 新增

- **智能去除背景（FR-SKN-002 扩展）**：设置 → 皮肤新增可选去背景步骤。边缘带量化直方图估色 + 四边洪泛连通域 + Alpha 距离映射 + 可分离盒式羽化；原图与透明结果双栏预览，容差 / 羽化 / 边缘采样带实时联动；结果可进入 4×2 八态切割或导出透明 PNG。无新依赖、不联网、不使用深度学习模型。
- **八态单图继续作为图片类唯一入口（FR-SKN-002）**：单张 4 列 × 2 行图片按行读取为 `idle / happy / sleep / work / click / drag / error / talk`，逐格裁留白、统一画布、底边对齐。
- **皮肤资源外置（NFR-PERF-004）**：皮肤图片与音效改为 `skins/*.json` 按引用存取；启动时自动迁移旧数据并清理未引用文件。
- **文档**：新增《方案：将极简图片背景去除工具合并到 DeskPet》落地记录，同步《自动裁剪规范》、ROADMAP 与中英词条。

## 修复

- **智能去除背景的边界处理**：对纯色、绿幕、蓝幕背景使用四边洪泛连通域，避免把主体内部相近颜色误判为背景；羽化使用可分离盒式模糊，保持 1600×1600 图像处理约 70–150 ms。
- **皮肤资源外置后的兼容性**：旧版 `data.json` 中内联的皮肤资源在启动时迁移；迁移后 `data.json` 只保留 `$blob` 引用，避免体积膨胀。

## 收敛与移除

- **移除「导入单张图片」入口**：原因：与「导入八态单图（4×2）」重复，单张图片无法表达完整八态，容易让用户误以为导入成功但动画缺失；用户迁移方式：改用八态单图或皮肤包。
- **移除「导入 Codex 宠物」入口**：原因：Codex Pet Contract 属于历史兼容能力，入口使用频率低且维护成本高；解析 / 导出实现保留用于历史数据兼容与回归测试，历史条目仍可切换 / 删除；用户迁移方式：使用八态单图或皮肤包。
- **皮肤导入上限明确为 128 MB / 64 MB / 256 MB / 200 条目**：原因：统一 zip、单文件、解压总量与条目数的防护边界，保留路径穿越与压缩炸弹防护。
- **本版本无默认开启能力新增**：去背景为主动操作，不改变任何默认值。

## 安全与隐私变更

- **外部输入解析（INT-009）**：皮肤包导入增加 / 保持大小、条目数、路径穿越、压缩炸弹与 SVG 清洗防线；不联网、不执行包内代码。
- **本地数据（INT-009）**：皮肤资源写入 `skins/*.json`，不进入模型上下文；日志不记录图片内容与用户路径。
- **未完成事项**：更新包签名 / 哈希校验（NFR-SEC-004）仍未实现，更新链路目前仅强制 HTTPS；详见《隐私与安全白皮书》第 9 节。
- **无新增出站域名**：去背景为纯前端处理，不产生网络请求。

## 验证

- 自动化：`cargo test` 全绿（含背景去除合成图、皮肤导入 / 导出、SVG 清洗、路径穿越用例）；前端脚本 `node --check` 通过；中英词条对齐。
- 手工验收：导入八态单图 → 切割、裁留白、底边对齐正常；导入皮肤包 → 可切换 / 删除；导入含 `../` 条目的包 → 整体拒绝；去背景后导出透明 PNG → 再进入八态切割成功。
- 性能：1600×1600 图像去背景约 70–150 ms（测试机为开发机，未形成正式性能报告）。
- 已知限制：去背景只适合纯色 / 绿幕 / 蓝幕等简单背景，复杂背景不保证效果；更新签名未实现。

## 升级说明

- 首次启动会自动迁移旧 `data.json` 中的皮肤资源到 `skins/*.json`，无需手动操作；迁移失败时保留原数据。
- 历史 Codex 皮肤条目仍可切换与删除，但不再提供导入 / 导出 / 帧维护入口。
- 旧日志会在启动时归档为 `deskpet.log.legacy-<时间戳>`，新日志为 JSON Lines。
