# v2.3.1 — 数据模式迁移与「配好了却还在演示模式」修复

> 发布日期：2026-11-13
> 基线：v2.3.0
> 对应提交：见本提交（`fix(chat)` + `feat(dat)` 合并于同一版本）

## 摘要

本版本补齐 FR-DAT-005 的最后一块：`data.json` 有了数据模式版本号与逐版本迁移框架，升级时自动迁移、失败保留原数据。同时修复一个影响核心体验的问题——用户配置好真实供应商后，对话仍返回「演示模式」的内置回复。

## 新增

- **数据模式版本号与迁移框架（FR-DAT-005）**：`data.json` 顶层 `schema` 记录数据模式版本，启动加载时按 `1 → 2 → …` 逐版本迁移；缺少迁移步骤或数据形状不符即中止，不回写半成品。
  - 迁移成功：迁移前的原始文件另存为 `data.json.pre-v<版本>-<时间戳>`，随后以新结构原子写回（沿用 tmp + 原子替换 + `.bak`）。
  - 迁移失败：另存 `data.json.corrupt-<时间戳>`，回退默认数据照常启动，写入 `data.load_fallback` 诊断日志；成功迁移写 `data.migrated`（只含版本号，不含任何正文）。
  - 数据模式**高于**当前程序支持版本时拒绝迁移，避免旧程序覆盖新版本数据。
  - 备份恢复（`backup_restore`）前先把备份状态迁移到当前模式，失败则拒绝恢复，现有数据不受影响。
- **「当前生效供应商」提示（设置 → 模型）**：直接显示本机对话实际使用的供应商与模型；处于演示模式时用醒目提示写明「回复为内置演示内容，不会调用任何模型」。

## 修复

- **配好真实供应商后，回复仍标注「演示模式 · 贴心小助手」（FR-MDL-006）**。触发条件：默认人格 `ps-1` 自身绑定 `p-demo`，历史会话把 `providerId` 钉在 `p-demo`；此后无论新建 / 设为默认真实供应商，会话绑定都不会被批量改写，前端 `activeProv()` 只认会话绑定、不回退，于是永远落到内置演示分支。
  - 现在：绑定失效（供应商被删除，或绑定仍是演示模式但用户已设真实默认）时，按「会话绑定 → 全局最后选择 → 默认供应商」逐级回退到**非演示**供应商。
  - 用户手动选回演示模式会被 `settings.mockPinned` 记住，不会被自动回退规则顶掉。
  - 切换供应商改为立即落盘（此前 200 ms 防抖，切完立刻关窗会丢失选择，下次打开又回到演示模式）。
  - 发送前若仍解析到演示模式且存在真实供应商，自动切换并在气泡提示一次，不再无提示地给出内置回复。
- **回归测试**：新增 `provider_selection_falls_back_to_real_default`，锁定回退规则并禁止 `activeProv` 退回「只认会话绑定」的旧实现。

## 收敛与移除

- 本版本无功能移除。
- 清理两个未使用函数（`load_or_default` 旧入口与重复的版本号解析），`cargo build` 恢复零警告。
- **无默认开启能力新增**：迁移与回退均为本地、被动行为，不改变任何默认值。

## 安全与隐私变更

- **数据迁移（FR-DAT-005）**：迁移完全在本地完成，不联网、不上传；诊断日志只记录版本号与失败原因，不含会话 / 记忆正文与密钥。
- **新增本地文件**：`data.json.pre-v<版本>-<时间戳>` 与 `data.json.corrupt-<时间戳>` 含对话与记忆，属高敏感本地文件，不自动上传；已同步写入《隐私与安全白皮书》数据地图。
- **未完成事项**：更新包签名 / 哈希校验（NFR-SEC-004）仍未实现。
- **无新增出站域名**。

## 验证

- 自动化：`cargo test` 75 passed（新增 6 个迁移测试 + 1 个供应商回退测试）；`cargo build --release` 无警告；`settings.html` / `bubble.html` / `pet.html` script 块语法检查、`node --check src/shared.js`、`node scripts/check-governance.mjs` 通过。
- 规则矩阵（用实际 `shared.js` 代码执行）：会话绑定 `p-demo` + 默认 DeepSeek → 真实模型；会话绑定已删供应商 → 真实模型；仅演示 → 演示；显式选回演示 → 演示；首启无会话 → 真实模型。
- 已知限制：未在真实 API Key 环境下做端到端请求验证，本次修的是「选择哪条分支」，真实请求链路未改动。

## 升级说明

- 首次启动会用新版本（数据模式 v2）自动迁移旧 `data.json`，同时保留 `data.json.pre-v1-<时间戳>` 作为回退副本，无需手动操作。
- 若此前配好供应商却一直得到演示回复：升级后打开对话即自动切到真实供应商；想继续用演示模式，在气泡 ⚡ 菜单里选一次即可。
