# v2.3.4 — 硬件加速开关与显卡兼容回退

> 发布日期：2026-11-17
> 类型：体验与兼容性补丁
> 关联需求：NFR-INT-006、AC-024

## 摘要

本版本补齐 P1 的 NFR-INT-006：设置 → 宠物与交互新增「关闭硬件加速」开关，默认保持 GPU 加速；开启后下次启动会让 WebView2 以 `--disable-gpu` 运行，用于缓解部分显卡驱动导致的闪烁、黑屏或透明区域花屏。开关只影响本机渲染方式，不产生网络请求，取消勾选并重启即可恢复。

## 新增

- **关闭硬件加速（NFR-INT-006）**：设置 → 宠物与交互 → 体型与层级新增复选框，默认关闭。
- **下次启动生效**：启动时在 `tauri::Builder` 与所有 WebView2 窗口创建之前读取 `settings.disableGpu`，追加 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--disable-gpu`。
- **参数安全合并**：保留系统 / 用户已有的浏览器参数，不覆盖、不重复追加；关闭开关后下次启动不再注入。
- **诊断日志**：启用时写 `perf.gpu_disabled`，只记录事件与固定说明，不含硬件型号或用户数据。
- **用户文档**：新增[《硬件加速与显卡兼容》](../硬件加速与显卡兼容.md)，说明症状、步骤、回退与边界。

## 修复

- 本版本无功能缺陷修复；主要解决部分显卡驱动环境下缺少渲染降级手段的问题。
- 旧 `data.json` 缺少 `disableGpu` 时按 `false` 处理，不迁移、不写回。

## 收敛与移除

- 本版本无功能移除。
- **默认值保持不变**：硬件加速默认开启，避免为了兼容少数环境而牺牲大多数用户的流畅度。
- 设置仅在下次启动生效，不提供进程内即时重建 WebView2 的入口。

## 安全与隐私变更

- **出站域名**：无新增；该开关不发起任何网络请求。
- **数据与日志**：只持久化一个布尔值 `settings.disableGpu`；日志写 `perf.gpu_disabled`，不含硬件标识。
- **权限 / 授权**：无变化；不新增系统权限、工具或感知源。
- **未完成事项**：
  - 仍无 Authenticode 代码签名，Windows SmartScreen 可能提示未知发布者；
  - NFR-UI-004（键盘 / 读屏）与 NFR-UI-002（字体缩放 / 高对比度）仍未系统适配；
  - 未检测具体显卡型号，也不自动诊断驱动。

## 验证

- 自动化：`cargo test` 82 passed（新增 `gpu_preference_defaults_off_and_merges_args`，覆盖默认值、参数合并、重复参数去重与状态读取）。
- 构建：`cargo build --release --target x86_64-pc-windows-gnu` 通过。
- 脚本：`src/settings.html` 内联脚本与 `src/i18n.js` / `src/shared.js` 语法检查通过。
- 待手工验收：开启开关 → 完全退出并重启 → 确认启动日志出现 `perf.gpu_disabled`，界面正常；取消勾选并重启 → 恢复硬件加速。
- 待手工验收：显卡驱动正常的环境默认不注入参数，设置保持关闭。
- 已知限制：未在真实故障显卡 / 远程桌面环境中复现并验证；参数注入的最终效果由 WebView2 运行时决定。

## 升级说明

- 无需手动操作；直接替换 `DeskPet.exe` 即可，数据文件与 Key 不受影响。
- 若不需要关闭硬件加速，保持默认即可；该设置不会自动开启。
- 开启或关闭后都需完全退出并重新启动 DeskPet，重复双击只会唤起已有实例。
