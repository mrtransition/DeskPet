# 硬件加速与显卡兼容（NFR-INT-006）

> 状态：v2.3.4 落地
> 关联需求：NFR-INT-006、NFR-UI-002
> 入口：设置 → 宠物与交互 → 体型与层级 → 关闭硬件加速

## 1. 为什么需要这个开关

DeskPet 使用系统 WebView2 渲染宠物、气泡与设置窗口。部分老显卡、远程桌面环境或驱动异常会导致：

- 窗口闪烁、黑屏或透明区域出现色块；
- 气泡打开 / 收起时短暂花屏；
- 高 DPI 缩放下文字或图片撕裂。

这类问题通常与 GPU 合成有关。开启「关闭硬件加速」后，下次启动会让 WebView2 以 `--disable-gpu` 运行，用 CPU 渲染换取稳定性。

## 2. 行为与边界

| 项 | 说明 |
|---|---|
| 默认值 | **关闭**（保持硬件加速） |
| 生效时机 | **下次启动**；切换后当前进程不改变渲染方式 |
| 实现方式 | 启动时读取 `data.json` 的 `settings.disableGpu`，若为 `true` 则在 WebView2 创建前设置 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--disable-gpu` |
| 参数合并 | 保留系统 / 用户已有的浏览器参数，不覆盖、不重复追加 |
| 恢复 | 取消勾选并重启，即可恢复硬件加速 |
| 日志 | 启动时写 `perf.gpu_disabled`（不含机器信息） |
| 网络 | 不产生任何网络请求 |

## 3. 使用步骤

1. 打开 设置 → 宠物与交互；
2. 在「体型与层级」中勾选「关闭硬件加速」；
3. 完全退出并重新启动 DeskPet（托盘 → 退出，或结束所有实例）；
4. 观察闪烁 / 黑屏是否缓解；
5. 若问题消失，可保留该设置；若想恢复性能，取消勾选并再次重启。

> 同一时间只运行一个实例，因此重启前请确认托盘中的旧实例已退出；重复双击只会唤起已有实例，不会自动应用新设置。

## 4. 验证与回归

- 单元测试：`gpu_preference_defaults_off_and_merges_args` 覆盖默认值、参数合并与重复参数去重；
- 数据兼容：旧 `data.json` 缺少 `disableGpu` 时按 `false` 处理，不迁移、不写回；
- 启动顺序：参数注入发生在 `tauri::Builder` 与所有 WebView2 窗口创建之前；
- 关闭开关后启动不会残留 `--disable-gpu`。

## 5. 未覆盖项

- 不提供进程内即时切换（WebView2 不支持安全地重建全部窗口）；
- 不检测具体显卡型号，也不自动诊断驱动；
- 不替代系统级驱动更新或远程桌面厂商的兼容设置；
- 代码签名（Authenticode）仍不在当前范围。
